- Public unified communications engineer role signals: Cisco voice applications, communication server clusters, outage and trouble-ticket resolution, capacity/performance/uptime/security reporting, documentation, project support, on-call escalation, training, and mentoring.
- Public role requirements: Cisco Unified Communications Manager, Cisco Unity Connection, Cisco Packaged Contact Center Enterprise, CUBE/Gateway troubleshooting, call recording applications, vendor relationship management, ServiceNow, Agile/ITIL, e911, scripting/API, Expressway/MRA, and IM & Presence.

- Cisco Unified Border Element documentation: dial peers, SIP configuration, DTMF relay, codecs, media path, SIP trunk monitoring, and troubleshooting.
- Cisco Packaged Contact Center Enterprise documentation: contact center routing, call processing, IVR scripting, agent selection, queuing, and reporting.
